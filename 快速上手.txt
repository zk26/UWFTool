========================================
 UWF 教师控制台 · 机房远程版 快速上手
========================================

【学生机（50 台，每台一次）】
  1. 复制 tools\启用远程管理.cmd 到学生机
  2. 右键 → 以管理员身份运行 → 重启
  3. 记下脚本显示的计算机名

【教师机：建档】
  1. 双击 UWFtool.exe → UAC 点“是”
     （如果 UAC 显示“未知发布者”：双击 tools\trust-publisher.cmd 信任一次）
  2. 先到“机器清单”填好学生机管理员账号，点【保存账号设置】
  3. 回到“机房总览”，点【搜索学生机】——自动扫描本机网段
     （禁 ping 的机器也会用端口 / ARP 发现），列出哪些机器装了 UWF，
     勾选后【加入机器清单】
     支持 192.168.1. / 192.168.1.10-60 / 192.168.1.0/24
     （找不到就手改网段；也可“按编号批量添加” PC-01…PC-50）
  4. 打开“母盘放行检查”→“重新检测”，
     红色 × 全部消掉后，这台机器才能做母盘/被远程管理
  5. 选中机器点【连接体检】确认四行都是 ✔

【每天上课前】
  “机房总览” → 【刷新全部状态】
  看顶部：保护中 50、暂停还原 0 就是正常

【远程装软件（重点）】
  0. 要装 50 台：先在“机房总览”把机器都建好并【全选】（更多操作 → 全选），
     再打开向导——向导的目标列表 = 总览里勾选的机器
  1. 在总览里勾选要装的机器
  2. 打开“远程安装” → 【开始远程安装向导】
  3. 第1步【关闭保护】——只是暂时关闭 UWF 保护，不是维修模式
  4. 第2步【重启所选】
  5. 第3步【重新检测】等机器全部在线，并确认日志写着“UWF 保护已关闭”
     （若提示还在保护：回第2步重启，先别装——容易写满缓存导致黑屏）
  6. 第4步选安装包，勾【静默安装】即可——程序会先识别安装包类型再给参数
     （Inno Setup→/VERYSILENT、NSIS→/S、MSI→/quiet /norestart，不用自己填，
     日志里会写“安装包类型：xxx，静默参数：xxx”）
     装不上就把【静默安装】的勾去掉重试，或在【附加参数】里换参数；
     输入法这类“按用户安装”的软件要勾【以登录用户运行】（装到学生账号下）
     点【分发并安装】—— 遮罩里会实时显示：
       “复制到 PC-07：312.4 / 698.1 MB（45%），12.4 MB/s，约剩 31 秒”
       “正在安装 PC-07：已用 3 分 12 秒”
     日志里也有：已复制完成 / 安装程序已启动（PID）/ 安装程序已结束
     卡住时先看这两行，就知道是卡在“复制”还是“安装”
     日志里还会回传安装包的输出和退出码（退出码非 0 = 参数不对 / 缺运行库；
     没输出 10 秒就退 = 很可能是在线安装包没外网，换离线完整包）
     【同时台数】默认 4 台并发，最多 8 台；勾【以登录用户运行】则安装界面
     会出现在学生机屏幕上（适合要点下一步的包，需机器上有人登录）
  7. 第5步【恢复还原】，然后第6步重启
  ★ 第5步不做，机器会一直不还原！

【装完怎么确认】
  总览刷新：保护=已开启、暂停还原=否；
  学生机重启后软件还在、桌面文件消失 → 正常。

【母盘：设置保护层大小】
  “本机状态” → 【启用保护】→ 选内存还是磁盘，
  内存、磁盘的上限和警告/严重阈值分别填（如磁盘 8192）
  → 应用并启用 → 重启
  ★ 两种都要整套配：只配一种，切到另一种时它还是默认小值，会被写满
    （内存缓存写满会直接拖垮系统）
  “母盘放行检查” 全部变绿后再对拷克隆

【母盘能不能做？】
  “本机 / 母盘 → 母盘放行检查”
  远程管理：服务 / C$ / WMI / 445、135 端口 / 工作组令牌
  母盘保护：UWF 组件、UWF 已开启、系统盘在保护列表
  红 × 必须处理；点【一键放行修复】可自动开服务、放行端口、补共享

【忘记恢复还原了】
  总览顶部“暂停还原”> 0 → 勾选这些机器 → 【恢复还原】→ 重启

【进某台机器的目录（看它 C 盘里有什么）】
  在总览表格里【双击那一行】→ 直接用资源管理器打开 \\计算机名\C$
  （用“机器清单”里的账号自动认证，不再单独弹密码框）
  也可以右键那一行选「打开目录」，或选中后点详情区右下角「打开目录」
  打不开时会提示原因：共享没开 / 防火墙拦了 / 账号不是管理员

【批量设置保护层（缓存）大小】
  勾选机器 → UWF ▼ 或 更多操作 ▼ → 【批量设置保护层（缓存）…】
  选 2/4/8/16 GB 预设（自动填好警告/严重阈值），或自己改三项数值
  一次下发到所有勾选机器，重启后生效
  （只改当前生效类型那套参数：内存 RAM / 磁盘 DISK 各一套）

【单台出问题】
  选中那台 → 【连接体检】，按提示处理；
  看“说明”列和“操作日志”。

【注意】
  · 机器离线（无法连接）时不能操作：批量暂停/恢复/重启/加排除/执行命令/远程安装
    会自动跳过离线机器并提示跳过了哪几台，双击也打不开目录。
    先确认开机和网络，再「刷新全部状态」；只有「刷新」「连接体检」对离线机器照样可用
  · 这个工具需要学生机的管理员权限，账号请妥善保管
  · 暂停还原期间机器不还原，装完立刻恢复
  · 专业版 / 家庭版没有 UWF，管不了
  · 刷新状态 / 批量操作 / 安装时会弹遮罩，等它自己消失再点，别重复点（会卡）
  · 装软件用「UWF ▼ → 关闭 UWF」或向导「关闭保护」，不要用「维修模式」
  · 「维修模式」只给 Windows 更新用：进入/退出都会自动重启，必须等所有电脑
    的 Windows 更新全部装完才能退出；中途退出或断电会黑屏。日常不要用。
